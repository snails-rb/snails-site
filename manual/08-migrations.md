# Migrations

You change the database schema the explicit way: write a numbered file under `db/migrate/`, apply it, and keep `db/schema.sql` as the snapshot your tests load. Nothing runs against the database until you say so.

## Start from the baseline

`snails new --scaffold` stamps the template's tables as the first migration — a UTC-numbered baseline — and tells you the next steps:

```text
20261107203440_baseline.sql
```

```sh
snails migrate apply
snails migrate dump
```

```text
applying 20261107203440_baseline
1 applied
[snails] snapshot regenerated (3 statements)
```

If `apply` fails with `unable to open database`, the `storage/` folder does not exist yet — start `bin/dev` once, or create the folder, and run it again.

## Change the schema

Add a numbered file for every change. The timestamp keeps files in apply order:

```sql
-- Slugs give posts a stable URL segment.
ALTER TABLE posts ADD COLUMN slug TEXT;
```

`snails migrate plan` prints the SQL of everything that has not been applied yet:

```text
-- 20261108090000_add_slug_to_posts (20261108090000_add_slug_to_posts.sql)
-- Slugs give posts a stable URL segment.
ALTER TABLE posts ADD COLUMN slug TEXT;
```

`snails migrate apply` runs it in order and records it:

```text
applying 20261108090000_add_slug_to_posts
1 applied
```

## Keep the snapshot in step

The tests load `db/schema.sql`, so regenerate it after every change:

```text
[snails] snapshot regenerated (3 statements)
```

The file header says it plainly — generated output, do not edit it:

```sql
-- Generated by snails migrate dump from db/migrate/*.sql — do not edit.
-- Edit the migration files, then re-run snails migrate dump.
```

`snails migrate status` shows where you stand at any time:

```text
[snails] 2 applied, 0 pending
20261107203440_baseline          applied
20261108090000_add_slug_to_posts applied
```

`snails migrate verify` confirms the snapshot still matches a replay of the migrations, and `snails migrate check` exits non-zero while anything is pending — useful before a deploy.
